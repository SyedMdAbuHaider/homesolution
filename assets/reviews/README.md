# Review screenshots

Drop customer review screenshots here, e.g. review1.webp, review2.webp ...

Then reference them in data/reviews.json under each entry's "image" field:

  "image": "assets/reviews/review1.webp"

No names or personal details are shown on the site — only the screenshot
itself (plus an optional star rating badge). To add or remove a review,
just add/remove an object in data/reviews.json and drop the matching
image here. No HTML edits required.

Recommended: .webp, portrait-ish crop (roughly 4:5), under 200KB each for
fast loading. Rating is optional — omit the "rating" field to hide the
star badge on that screenshot.
